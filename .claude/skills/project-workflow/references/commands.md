# Commands
- Install: `cd erp-portal; npm.cmd install`
- Lint: 미구성
- Typecheck: `cd erp-portal; npm.cmd run typecheck`
- Persistence scenario: `cd erp-portal; npx.cmd tsx scripts/store-persistence-scenario.ts`
- Integration test: `cd erp-portal; npx.cmd tsx scripts/e2e-scenario.ts`
- Build: `cd erp-portal; npm.cmd run build`
